# LFTR Fuel 3 Balance Calculator

This script computes the closed-loop balance of LFTR Fuel 3 production in GTNH 2.9.
Given a target number of reactors, it calculates the required external inputs,
surpluses (voided outputs), and the number of machines needed to sustain the cycle.

## Prerequisites
- Python 3 (stdlib only)
- `recipes.sqlite` database (generated by the `gtnh-rag` tool)

## Usage
```bash
python3 lftr_fuel3_balance.py [--db PATH] [REACTOR_COUNT]
```
- `--db PATH`: Path to the `recipes.sqlite` file. Falls back to `GTNH_RECIPES_DB` environment variable or `./recipes.sqlite`.
- `REACTOR_COUNT`: Number of reactors to balance for (default: 16).

## Note on Sparge Tower
The figures for the Sparge Tower are wiki-sourced assumptions because the recipe dump reports 0 for those random output ranges.
